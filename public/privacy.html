STILL HARBOR

Privacy, without surprises.

Privacy policy · Updated October 15, 2026 · Release 0.3.6

Purpose and data use

Still Harbor helps you set browsing boundaries and reflect on your active browsing time. It processes the current page URL, including paths and search parameters, temporarily to match your rules. It does not record visited full URLs, search terms, page contents, keystrokes or passwords entered into websites.

Browsing insights record hostnames and daily active-time totals on your device. Recording is enabled while the extension is running in normal browsing, even if blocking is paused. There is no account, cloud sync, advertising, sale of data or extension telemetry.

Local storage and retention

Chrome local extension storage holds your rules (including intentionally entered URL prefixes, keywords and redirect destinations), settings and insights. No website logo or icon cache is saved. If you set a protection password, a random salt and a PBKDF2-SHA-256 verifier are stored, not the plaintext password. Temporary activity, unlock and failed-attempt state uses Chrome session storage.

Insights are retained for up to 90 local calendar days. Expired entries are pruned when Chrome and the extension run; pruning cannot run while the browser is closed. Rules and settings remain until you remove them or clear the extension's data.

Incognito blocking is optional and requires you to turn on Allow in Incognito in Chrome's extension details. The same boundaries apply in private windows. Private URLs are processed temporarily for blocking, but private browsing activity is never recorded in insights or exports. The separate private worker reads shared settings, but does not read or write insights, activity or password unlock state. Manage settings, insights and exports in a regular window.

Optional website icons and external destinations

Website icons and icon requests are off by default. Only your explicit opt-in allows HTTPS favicon.ico requests to individual boundary domains, sometimes trying their www hostname. These sites receive your IP address and normal connection metadata. Requests omit cookies and referrers, refuse redirects, use no-store and do not use a third-party icon service.

Icons exist temporarily in memory while requested and displayed, not in extension storage or a retained icon cache. There is no bundled website artwork or Chrome favicon-cache lookup. Revisiting or reloading the list may contact sites again. Turning requests off cancels pending fetches and removes displayed icons. Upgrading from earlier versions deletes the old saved icon cache and requires fresh opt-in. Custom redirect destinations are ordinary browser navigations; the destination receives the data normally sent by your browser, subject to that site's privacy policy.

Your controls

Settings let you export insights as CSV or rules and insights as JSON, delete insights and disable icon requests. Exports are unencrypted files you control and omit the password verifier. Deleting insights does not delete rules, and recording resumes afterwards. For complete removal, uninstall the extension and clear any retained extension data in your browser; separately delete any exported files.

Password protection is a deterrent, not tamper-proof security. There is no password recovery; resetting through removal and reinstallation may lose all local rules and insights.

Sharing and Limited Use

The publisher does not receive your locally stored browsing data. There is no automated upload to the publisher, advertisers or data brokers. Only the optional website requests and user-chosen navigations described above contact external sites. If you voluntarily send exports for support, review their contents first.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only for the disclosed browsing-boundary and insights features, not advertising, credit decisions or unrelated purposes.

Changes and contact

Material changes to data practices will be disclosed in the extension and in an updated policy before they take effect. For privacy questions, contact the publisher using the support contact provided on Still Harbor's Chrome Web Store listing.
